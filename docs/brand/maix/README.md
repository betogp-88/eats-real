# Marca Maíx

Logo: monograma "M" con mazorca dentro de un círculo, en negro sobre blanco. Archivo `logo-1024.png`; en la app se usa `public/logos/maix.png` (512 px).

Como el logo es monocromo, la paleta del admin usa negro como primario y un dorado de maíz como acento.

| Uso                | Hex       | Variable en Vercel               |
|--------------------|-----------|----------------------------------|
| Primario (barra, botones) | `#1a1a1a` | `NEXT_PUBLIC_COLOR_PRIMARIO`      |
| Secundario (positivo, hover) | `#b89b5e` | `NEXT_PUBLIC_COLOR_SECUNDARIO`  |
| Acento (acciones destacadas) | `#d9a521` | `NEXT_PUBLIC_COLOR_ACENTO`      |
| Acento suave        | `#f1e2b3` | `NEXT_PUBLIC_COLOR_ACENTO_SUAVE` |
| Fondo               | `#f7f5f0` | `NEXT_PUBLIC_COLOR_FONDO`        |
